**NBTExplorerCLI** (`nbtcli.exe`, v1.0.0) is a CLI for **Minecraft Java Edition** saves. Extract the full release ZIP and run `nbtcli.exe` from the extracted folder. The ZIP includes the .NET runtime.

<DocsHub lang="en" />

:::note[Two Ground Rules Before Modifying Any Save]
Always test on a **copy** of your world (such as `D:\WorldCopy`) and **close Minecraft** before running `apply` or `--apply`. Read-only and preview commands never touch your world folder.
:::

<details>
<summary>Reading Command Output (JSON) & CLI Message Language</summary>

Every command prints one clean line of JSON with three key fields:

```json title="Example output"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "version",
  "outcome": "Success",
  "data": { "product": "nbtcli", "version": "1.0.0" },
  "error": null
}
```

- **`success`**: `true` means it worked; `false` means it stopped safely.
- **`data`**: The value, summary, or plan metadata you requested.
- **`error`**: When `success` is `false`, `error.message` explains what went wrong.

CLI help, diagnostics, and translation prompt instructions are always in English (`--ui-locale en-US` is accepted explicitly). This website provides English and Traditional Chinese guides, and map content can be translated between any valid language tags.
