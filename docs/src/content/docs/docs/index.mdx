**NBTExplorerCLI** (`nbtcli.exe`, version `1.0.0`) is a free, ready-to-run Windows command-line tool for **Minecraft Java Edition** worlds. You do not need to install .NET or Java separately — just download the ZIP from GitHub Releases, unzip it, and run commands in PowerShell.

Whether you want to peek inside a save file, translate an entire adventure map into another language, package a resource pack, or let an AI assistant help you edit a world safely, this documentation walks you through every step in plain language.

## Who Is This Tool For?

<CardGrid>
  <Card title="Great For">
    - **Adventure Map Translators & Players**: Automatically collect text from signs, books, items, entities, scoreboards, bossbars, command blocks, and datapacks into clean pages — translate by hand or with AI.
    - **Mapmakers & Server Admins**: Check or update `level.dat`, region chunks (`.mca`), entities, and datapacks while Minecraft is closed, with built-in previews and automatic backups.
    - **AI Assistants & PowerShell Scripts**: Every command outputs clean JSON, making it easy for Claude, ChatGPT, Codex, Cursor, or your own scripts to inspect and translate worlds accurately.
  </Card>
  <Card title="Not Built For">
    - **Editing While Minecraft Is Running**: Always close Minecraft (and other map tools) before applying changes so your save never gets corrupted.
    - **3D Visual Block Building**: This is a text-based command-line tool, not a 3D map viewer.
    - **Minecraft Bedrock Edition Saves**: Only **Minecraft Java Edition** worlds are supported. Run `nbtcli capabilities` to check exact version support.
  </Card>
</CardGrid>

## Safety Labels Used Across This Guide

Every page and command shows one of three color-coded labels so you always know if an action can touch your Minecraft save:

| Safety Label | What Happens to Your World Folder |
| --- | --- |
| **Read Only** | Only reads data or checks status. Your world folder is never modified. |
| **Preview Only** | Creates a reviewable plan file or saves translation progress in a separate folder outside your world. Your world folder stays untouched. |
| **Modifies World** | Writes changes into your world folder. Always test on a copy first, close Minecraft, and pass `--world-offline`. |

## Reading Command Output in 10 Seconds

Every command prints one clean block of JSON text. You only need to look at **three fields**:

```json title="Example output"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "version",
  "outcome": "Success",
  "data": {
    "product": "nbtcli",
    "version": "1.0.0"
  },
  "error": null
}
```

1. **`success`**: `true` means it worked; `false` means something stopped it.
2. **`data`**: The answer you asked for (for example, your world name, version number, or translation progress).
3. **`error`**: When `success` is `false`, `error.message` explains in plain language what went wrong.

### Switching Message Language (`--ui-locale`)

You can add `--ui-locale en-US` or `--ui-locale zh-TW` to any command to choose whether help and error messages appear in English or Traditional Chinese. This only changes tool messages — it never changes your Minecraft world language settings (`--source-language` / `--target-language`).
