**NBTExplorerCLI** (`nbtcli.exe`, v1.0.0) is a ready-to-run Windows command-line tool for **Minecraft Java Edition** saves. Unzip the release, open PowerShell, and inspect worlds, translate adventure maps, or build resource packs — no extra .NET or Java install needed.

<DocsHub lang="en" />

:::note[Two Ground Rules Before Modifying Any Save]
Always test on a **copy** of your world (such as `D:\WorldCopy`) and **close Minecraft** before running `apply` or `--apply`. Read-only and preview commands never touch your world folder.
:::

<details>
<summary>Reading Command Output (JSON) & Switching UI Language</summary>

Every command prints one clean line of JSON with three key fields:

```json title="Example output"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "version",
  "outcome": "Success",
  "data": { "product": "nbtcli", "version": "1.0.0" },
  "error": null
}
```

- **`success`**: `true` means it worked; `false` means it stopped safely.
- **`data`**: The value, summary, or plan metadata you requested.
- **`error`**: When `success` is `false`, `error.message` explains what went wrong.

Add `--ui-locale en-US` or `--ui-locale zh-TW` to switch help and error text language at any time (this never changes your world's translation languages).

</details>
