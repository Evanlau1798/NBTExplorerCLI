**NBTExplorerCLI** (`nbtcli.exe`, version `1.0.0`) is a self-contained Windows x64 command-line tool built for **Minecraft Java Edition** worlds (`1.12.2` through `1.21.11`, `DataVersion` `1343` to `4671`). It enables players, adventure map creators, localization teams, and tool developers to inspect NBT data, scan and translate in-world text, generate resource packs, and apply verified offline edits.

<SafetyBanner tier="safe" lang="en" />

## When to Use NBTExplorerCLI

<CardGrid>
  <Card title="Built For">
    - **Adventure Map Localization Teams**: Scanning thousands of signs, books, items, command blocks, and datapack entries into structured pages and glossaries.
    - **Technical Creators & Server Admins**: Inspecting or batch-modifying `level.dat`, `.mca` region chunks, entities, and datapacks offline with SHA-256 precondition checks and pre-write backups.
    - **Automation Scripts & AI Agents**: Driving world inspection and translation via deterministic single-line JSON responses and machine-readable exit codes (`0` through `8` and `130`).
  </Card>
  <Card title="Not Designed For">
    - **Live In-Game Editing**: World-modifying commands require Minecraft and other editors to be closed (`--world-offline`) so region files and metadata are never corrupted by concurrent writes.
    - **3D Viewport Terrain Rendering**: NBTExplorerCLI is a deterministic command-line engine rather than a 3D visual block editor.
    - **Minecraft Bedrock Edition Saves**: The storage and NBT codecs target **Minecraft Java Edition** saves only.
  </Card>
</CardGrid>

## Understanding Operation Safety Levels

Every guide and command in this documentation displays one of three plain-language safety labels so you always know whether an action can affect your Minecraft save files:

| Safety Badge | What It Means for Your World Save |
| --- | --- |
| **Safe to Inspect** | Reads files or checks external status logs only. Your Minecraft world folder is never modified. |
| **Preview Only** | Creates a change plan (`nbtcli.patch-plan`) or saves translation progress in an external directory outside your world. Your world files remain untouched. |
| **Modifies World Save** | Writes changes to your world folder. Always work on a world copy, close Minecraft and other editors first, and pass `--world-offline`. |

## One Predictable JSON Response Format

Every invocation of `nbtcli.exe` writes exactly one newline-delimited UTF-8 JSON object to standard output (`stdout`):

```json title="stdout (nbtcli.cli)"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "version",
  "outcome": "Success",
  "data": {
    "product": "nbtcli",
    "version": "1.0.0"
  },
  "error": null
}
```

### Interface Language vs. Translation Languages

NBTExplorerCLI strictly separates the language of CLI messages from the languages of your Minecraft world text:

- **CLI Interface Language (`--ui-locale`)**: Accepts `zh-TW` (default) or `en-US` before or after any command. It controls human-readable `error.message` and instruction text without changing JSON keys, machine error codes, or world data.
- **World & Resource Languages**: Flags such as `--source-language`, `--target-language`, `--lang`, `--original-lang`, and `--target-lang` control how Minecraft text and resource pack language files (such as `en_us` and `zh_tw`) are processed.
