This page lists every registered command and subcommand in **NBTExplorerCLI** (`nbtcli.exe`), aligned with the verified command surface contract (`nbtcli.command-surface`, version `1`).

## Global CLI Rules

For subcommand help, append `--help` to its invocation, for example `nbtcli translate start --help`.

- **Single JSON Output**: Every command writes exactly one newline-delimited UTF-8 JSON envelope (`schemaFamily: "nbtcli.cli"`, `schemaVersion: 1`) to `stdout`.
- **Global Display Locale (`--ui-locale`)**: Pass `--ui-locale zh-TW` (default) or `--ui-locale en-US` before or after any command to select the language of error and help messages. It does not affect translation source/target locales (`--source-language`, `--target-language`, `--lang`, `--original-lang`, `--target-lang`).
- **Option Syntax**: Value options accept `--option value` or `--option=value`. Boolean flags take no value. Use `--` to end option parsing when a path begins with a hyphen.
- **Root and Option Aliases**:
  - Root `--help` and `-h` invoke `help`.
  - Root `--version` and `-v` invoke `version`.
  - `-h` is accepted as `--help` on any command.

## File and Standard Input (`-`) Schemas

Commands that read structured JSON from a file or standard input (`-`) validate the exact `schemaFamily` and `schemaVersion` before executing:

| Input Schema Family | Accepted By |
| --- | --- |
| `nbtcli.typed-nbt` | `set --value <json>` or `set --value-file <file\|->` |
| `nbtcli.operations` | `batch <file\|-> --world <dir>` or `plan <dir> --request <file\|->` |
| `nbtcli.patch-plan` | `apply <dir> --plan <file\|->` |
| `nbtcli.session-reply` | `translate submit --reply <file\|->` or `translate advance --reply <file\|->` |
| `nbtcli.session-command` | `translate jump`, `note`, `glossary`, or `reset` via `--request <file\|->` |
| `nbtcli.agent-questionnaire` | `agent submit <dir> --request <file\|->` |
