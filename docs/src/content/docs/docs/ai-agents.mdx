## 2. High-Density Protocol Summary (For Agents)

For the flag matrix, 8 input schemas, 17 Java format families, classic Anvil limits, and 9 walkthroughs, read **[`llms.txt`](../../llms.txt)** directly. The core contract is summarized below.

### Core Invariants

| Invariant | Exact Rule |
| :--- | :--- |
| **Output Envelope** | Every call writes one newline-delimited UTF-8 JSON object (`schemaFamily: "nbtcli.cli"`, `schemaVersion: 1`) to `stdout`. Check both `$LASTEXITCODE` and `response.success`. |
| **Help Syntax** | Root: `nbtcli help <cmd>` or `nbtcli <cmd> --help`. Subcommand: `nbtcli translate <subcmd> --help` / `nbtcli agent <subcmd> --help`. (`nbtcli help translate start` exits `2`.) |
| **Fixed English CLI** | Help, errors, diagnostics, and translation prompt instructions are always English. `--ui-locale en-US` is accepted explicitly; any other value exits `2`. Map content languages are independent. |
| **Auto & Bound Languages** | `translate start` and `translate fallback` allow omitting `--source-language` (auto-detected or `und`) and `--target-language` (Windows display language). Languages bind at creation and persist across resumes/replies. If source is `und`, `export-lang`/`create-pack` require `--original-lang <language>`. |
| **External Paths** | Never place `--output`, `--plan-output`, `--state-root`, or `--cache-root` inside `<world>`. Pre-create parent directories before calling export commands. |
| **Offline Writes** | All world-modifying commands require `--world-offline` while Minecraft and other editors are closed. Prefer preview -> inspect -> `apply --plan <file> --world-offline`. |
| **Resource Export Default** | `translate export-lang` and `translate create-pack` default to inside `<world>` if `--output` is omitted. Always pass an explicit external `--output` to keep `<world>` untouched. |
| **State Root Continuity** | Reuse the identical `--state-root` across related `plan`, `apply`, `status`, `recover`, `backup`, `restore`, `translate`, and `agent` calls. Default: `%LOCALAPPDATA%\nbtcli\worlds\<world-id>`. |

### Exit Code Branching Matrix

| Exit Code | Meaning | Required Agent Action |
| :--- | :--- | :--- |
| `0` | `Success` | Continue workflow. |
| `1` | `InternalFailure` | Inspect `error.code`/`details`; stop before retrying writes. |
| `2` | `InvalidArguments` | Check exact flags via `<cmd> [<subcmd>] --help`. Zero files touched. |
| `3` | `Conflict` | Target world/session changed since preview/start, or `operationId` reused with different payload. Re-read & re-plan (or start new session + query `translate memory`). |
| `4` | `Unsupported` | Check `capabilities`, narrow the scope with `--path`/`--dimension`/`--types`, or specify `--minecraft-version` for classic Anvil saves. |
| `5` | `IoOrValidation` | Missing/locked file or malformed NBT/JSON. Confirm Minecraft is closed; run `validate` to pinpoint failing relative paths. |
| `6` | `ResourceLimit` | Exceeded 64 MiB output, 100k slots/ops, 256-segment depth, or 100 ms regex timeout. Narrow scope or lower `--page-size`/`--page-bytes`. |
| `7` | `RecoveryRequired` | Interrupted write. Do **not** open Minecraft or start new writes. Run `status --plan-hash <hash>` (or `data.pendingPlanHash`), then `recover` (exit `0`) or `recover --rollback` (exit `8`). |
| `8` | `RolledBack` | `recover --rollback` restored verified pre-edit bytes. Never treat as forward apply success. |
| `130` | `Cancelled` | Cancelled receipt; if interrupted mid-write, run `status` + `recover`. |

### Fast-Path Workflows

```powershell title="1. Single Typed Edit (always source from get --types)"
New-Item -ItemType Directory -Path 'D:\Plans' -Force | Out-Null
$r = .\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/LevelName --types | ConvertFrom-Json
if (-not $r.success) { throw $r.error.message }
$val = $r.data.value
$val.data.root.value = 'New Map Name'
$val | ConvertTo-Json -Depth 50 | Set-Content -Encoding utf8 'D:\Plans\val.json'
.\nbtcli.exe set 'D:\WorldCopy' --path level.dat --pointer /Data/LevelName --value-file 'D:\Plans\val.json' --output 'D:\Plans\plan.json'
.\nbtcli.exe apply 'D:\WorldCopy' --plan 'D:\Plans\plan.json' --world-offline --output 'D:\Plans\receipt.json'
```

```powershell title="2. Paginated Translation Loop (translate start -> export/advance -> plan -> apply -> seal)"
New-Item -ItemType Directory -Path 'D:\Translate' -Force | Out-Null
# Omit language flags for automatic source detection + Windows display target, or add --source-language ja-JP --target-language de-DE
$s = .\nbtcli.exe translate start 'D:\WorldCopy' --page-size 30 | ConvertFrom-Json
$sid = $s.data.status.sessionId
# Loop: export page -> mutate data.replyTemplate slots ("translated" + text, or "unchanged" + null) -> submit/advance until pending == 0
# Finish:
$opId = [guid]::NewGuid().ToString()
$rev = (.\nbtcli.exe translate status 'D:\WorldCopy' --session-id $sid | ConvertFrom-Json).data.status.revision
.\nbtcli.exe translate plan 'D:\WorldCopy' --session-id $sid --revision $rev --direct --operation-id $opId --output 'D:\Translate\plan.json'
.\nbtcli.exe apply 'D:\WorldCopy' --plan 'D:\Translate\plan.json' --world-offline --output 'D:\Translate\receipt.json'
$planHash = (Get-Content -Raw 'D:\Translate\plan.json' | ConvertFrom-Json).data.planHash
.\nbtcli.exe translate seal 'D:\WorldCopy' --session-id $sid --revision $rev --operation-id $opId --plan-hash $planHash
```

```powershell title="3. Validated Fallback Draft for Unresolved Sources (translate fallback)"
.\nbtcli.exe translate fallback 'D:\dialogue.nbt' --pointer /dialogue
.\nbtcli.exe translate fallback 'D:\dialogue.nbt' --pointer /dialogue --text-pointer /caption
# Fill data.replyTemplate (nbtcli.translation-draft-reply, schemaVersion 2) and repeat the exact selection + --text-pointer:
.\nbtcli.exe translate fallback 'D:\dialogue.nbt' --pointer /dialogue --text-pointer /caption --reply 'D:\reply.json'
```

### Top Pitfalls Agents Must Avoid

1. **Never pass bare values to `set`** — Always wrap inside `nbtcli.typed-nbt` sourced from `get --types` (`data.value`).
2. **Never drop unchanged slots from `nbtcli.session-reply`** — Every slot exported on the page must be present (`"translated"` or `"unchanged"` with `"text": null`), keeping all hashes and IDs untouched.
3. **Never write `--output` into a non-existent folder or inside `<world>`** — Create external parent folders first.
4. **Never translate identifying entity `CustomName` blindly** — Command selectors (`@e[name=...]`) are protected by default; only use `--synchronize-references` in `translate plan --direct` when explicitly intended.
5. **Never skip live verification claims** — CLI validation verifies NBT/JSON framing and hashes, not in-game rendering or runtime command behavior.
