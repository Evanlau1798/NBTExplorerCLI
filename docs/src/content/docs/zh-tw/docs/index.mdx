**NBTExplorerCLI**（`nbtcli.exe`，版本 `1.0.0`）是一款免費、解壓縮就能直接使用的 Windows 命令列工具，專為 **Minecraft Java Edition** 世界存檔打造。**不需要另外安裝 .NET 或 Java**——只要從 GitHub Releases 下載壓縮檔、解壓縮，就能在 PowerShell 中開始使用。

不管你是想查看存檔裡藏了什麼資料、把整張英文冒險地圖翻成繁體中文、匯出資源包，或是交給 AI 助手幫你自動處理地圖文字，這份網站都會用最白話、一步一步的方式帶你上手。

## 這個工具適合誰使用？

<CardGrid>
  <Card title="非常適合用於">
    - **冒險地圖翻譯者與一般玩家**：自動收集告示牌、書本、物品、實體、計分板、Boss 血條、指令方塊與資料包文字，整理成好讀的一頁一頁，自己翻或交給 AI 翻都超方便。
    - **地圖作者與伺服器管理員**：在關閉 Minecraft 的離線狀態下查閱或修改 `level.dat`、區塊（`.mca`）、實體與資料包，內建寫前預覽與自動備份保護。
    - **AI 助手與自動化腳本**：每個指令都輸出乾淨統一的 JSON 格式，讓 Claude、ChatGPT、Codex、Cursor 或 PowerShell 腳本都能精準安全地操作存檔。
  </Card>
  <Card title="不適用於">
    - **開著 Minecraft 即時修改**：所有會修改存檔的操作都必須先關閉 Minecraft 與其他編輯器，避免遊戲同時讀寫導致存檔損壞。
    - **3D 視覺化蓋房子或方塊檢視**：這是純文字的命令列工具，不包含 3D 地圖預覽畫面。
    - **Minecraft 基岩版（Bedrock Edition）存檔**：僅支援 **Minecraft Java Edition**。隨時可執行 `.\nbtcli.exe capabilities` 查詢確切支援版本。
  </Card>
</CardGrid>

## 看懂本網站的三種安全標籤

網站中每篇教學與每個指令都會標示三種顏色的安全等級，讓你在按 Enter 之前一眼確認會不會改到原存檔：

| 安全標籤 | 對你的 Minecraft 世界資料夾有什麼影響 |
| --- | --- |
| **純讀取：不改存檔** | 只讀取資料或檢查紀錄，絕不會改動你的世界資料夾。 |
| **僅預覽：先出計畫** | 只會在世界資料夾外建立預覽計畫或儲存翻譯進度，原世界檔案完全不動。 |
| **會修改存檔：先關遊戲** | 會實際寫入指定的世界資料夾。請務必先複製一份世界測試、關閉 Minecraft，並加上 `--world-offline`。 |

## 10 秒看懂指令輸出

每個指令執行後都會印出一段結構化的 JSON 文字。一般使用時只要看懂**三個欄位**就夠了：

```json title="輸出範例"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "version",
  "outcome": "Success",
  "data": {
    "product": "nbtcli",
    "version": "1.0.0"
  },
  "error": null
}
```

1. **`success`**：`true` 代表成功；`false` 代表遇到問題而中止。
2. **`data`**：這次指令查到或產生的結果（例如地圖名稱、版本號碼或翻譯進度）。
3. **`error`**：當 `success` 為 `false` 時，直接看 `error.message` 就能知道發生了什麼事。

### 切換提示訊息語言（`--ui-locale`）

在任何指令加上 `--ui-locale zh-TW`（繁體中文，預設）或 `--ui-locale en-US`（英文），即可切換錯誤訊息與說明文字的語言。這只會改變工具自己的提示語言，不會影響你的地圖翻譯語言設定（`--source-language` / `--target-language`）。
