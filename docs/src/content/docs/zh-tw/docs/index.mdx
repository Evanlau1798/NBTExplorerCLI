**NBTExplorerCLI**（`nbtcli.exe`，v1.0.0）是解壓縮即用的 Windows 工具，專為 **Minecraft Java Edition** 存檔設計。免另外安裝 .NET 或 Java，就能唯讀查閱存檔、翻譯整張冒險地圖並打包資源包。

<DocsHub lang="zh-tw" />

:::note[修改存檔前的兩個原則]
永遠先在**世界副本**（例如 `D:\WorldCopy`）上測試，並在執行 `apply` 或 `--apply` 前**完全關閉 Minecraft**。所有純讀取與預覽指令都不會更動你的世界資料夾。
:::

<details>
<summary>10 秒看懂指令 JSON 輸出與切換提示語言（--ui-locale）</summary>

每個指令都會輸出一行結構化 JSON，日常使用看這三個欄位即可：

```json title="輸出範例"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "version",
  "outcome": "Success",
  "data": { "product": "nbtcli", "version": "1.0.0" },
  "error": null
}
```

- **`success`**：`true` 代表成功；`false` 代表遇到問題而中止。
- **`data`**：查到的數值、掃描統計或計畫資訊。
- **`error`**：當 `success` 為 `false` 時，看 `error.message` 即可知道原因。

在任何指令加上 `--ui-locale zh-TW`（預設）或 `--ui-locale en-US` 可切換錯誤與說明文字的語言，不會影響地圖翻譯語言設定。
