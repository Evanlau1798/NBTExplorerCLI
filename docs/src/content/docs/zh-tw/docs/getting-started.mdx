即使你平常很少碰命令列（PowerShell），跟著這篇從頭做到尾，大約 3 分鐘就能完成安裝並安全查閱你的第一個 Minecraft Java 版世界。

## 第一部分：下載與準備（約 1 分鐘）

<Steps>

1. **從 GitHub Releases 下載 Windows 壓縮檔**

   打開官方 **[GitHub Releases 頁面](https://github.com/Evanlau1798/NBTExplorerCLI/releases)**，在最新版本下載 **`nbtcli-win-x64.zip`**。

   :::tip[不需要另外安裝 .NET 或 Java]
   所有執行需要的元件都已經包在這個壓縮檔裡面，下載解壓縮就能直接用。
   :::

2. **把整個壓縮檔解壓縮到同一個資料夾**

   在檔案總管裡對 `nbtcli-win-x64.zip` 按右鍵選「**解壓縮全部...**」，建議放到路徑簡單、沒有特殊符號的資料夾，例如 `C:\Tools\nbtcli`。

   :::caution[不要把 `nbtcli.exe` 單獨拉出來]
   請讓 `nbtcli.exe` 和同資料夾裡的所有 `.dll`、`.json` 檔案保持在一起。如果只把 `.exe` 搬走，程式會無法啟動。
   :::

3. **在這個資料夾裡打開 PowerShell**

   打開 `C:\Tools\nbtcli` 資料夾後，任選下面一種最順手的方法：
   - **方法 A（最推薦）**：點一下檔案總管最上方的「路徑網址列」，輸入 `powershell` 後按 **Enter**。
   - **方法 B**：按住鍵盤 **Shift** 鍵，在資料夾空白處點滑鼠右鍵，選「**在終端機中開啟**」（或「在此處開啟 PowerShell 視窗」）。

4. **確認 `nbtcli.exe` 可以正常啟動**

   在 PowerShell 視窗輸入下面這行並按 **Enter**：

   ```powershell title="PowerShell"
   .\nbtcli.exe --version
   ```

   正常會看到類似這樣的輸出：

   ```json title="輸出結果"
   {
     "schemaFamily": "nbtcli.cli",
     "schemaVersion": 1,
     "success": true,
     "command": "version",
     "outcome": "Success",
     "data": {
       "product": "nbtcli",
       "version": "1.0.0"
     },
     "error": null
   }
   ```

   :::note[如果 Windows 跳出「Windows 已保護您的電腦」（SmartScreen）]
   因為這是沒有付費商業數位簽章的開源工具，第一次執行時 Windows 可能會跳出提醒畫面。只要你確實是從上方官方 GitHub Releases 下載的，點選「**其他資訊**」->「**仍要執行**」即可。
   :::

   隨時可以查看所有指令或單一指令的說明：

   ```powershell title="PowerShell"
   .\nbtcli.exe --help --ui-locale zh-TW
   .\nbtcli.exe help get --ui-locale zh-TW
   .\nbtcli.exe translate start --help --ui-locale zh-TW
   ```

5. **複製一份測試用的 Minecraft 世界副本**

   雖然唯讀查閱完全不會改動存檔，但養成「永遠先在副本上操作」的習慣，才能讓原本的存檔萬無一失：
   1. **先完全關閉 Minecraft**（確保遊戲已經把最新進度存回硬碟）。
   2. 按鍵盤 `Win + R`，輸入 `%APPDATA%\.minecraft\saves` 後按 **Enter**，就會打開原版啟動器的存檔資料夾。
      *（若使用 Prism Launcher、CurseForge 或 Modrinth 啟動器，請在該啟動器打開實例資料夾，裡面就會看到 `saves`。）*
   3. 把想測試的世界資料夾**複製**一份出來，貼到好打字的路徑，例如 `D:\WorldCopy`。

</Steps>

## 第二部分：試跑前四個「純讀取」指令

以下四個指令都屬於**純讀取模式**，保證不會修改 `D:\WorldCopy` 裡的任何檔案。操作時請把 `D:\WorldCopy` 換成你自己的世界副本路徑。

### 1. 查看世界有哪些維度與區塊（`list`）

```powershell title="PowerShell"
.\nbtcli.exe list 'D:\WorldCopy'
```

這會列出世界包含哪些維度（主世界、地獄、終界或自訂維度）以及各自有多少個區塊檔（`.mca`）。

### 2. 讀取單一存檔欄位（`get`）

來讀看看 `level.dat` 裡記錄的 Minecraft 資料版本與世界名稱：

```powershell title="PowerShell"
# 查看世界的 Minecraft DataVersion 版本號
.\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/DataVersion

# 查看世界的顯示名稱
.\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/LevelName
```

各參數白話說明：
- `'D:\WorldCopy'`：你的世界副本路徑（用單引號 `'...'` 包起來，路徑裡有空格也不會出錯）。
- `--path level.dat`：要打開世界裡的哪一個檔案。
- `--pointer /Data/DataVersion`：要讀檔案裡的哪一個欄位（跟資料夾路徑一樣用 `/` 往下找：`Data` 底下的 `DataVersion`）。

輸出範例：

```json title="輸出結果"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "get",
  "outcome": "Success",
  "data": {
    "representation": "display-json",
    "tagType": "Int",
    "value": 3953
  },
  "error": null
}
```

看 `data.value`：`3953` 就代表這張地圖是 Minecraft Java `1.21`！

### 3. 不知道路徑在哪裡？用關鍵字搜尋（`search`）

如果不確定欄位叫什麼全名，可以直接用 `--name`（搜欄位名稱）或 `--query`（搜文字內容）：

```powershell title="PowerShell"
# 在 level.dat 裡搜尋名稱包含 "Spawn" 的所有欄位
.\nbtcli.exe search 'D:\WorldCopy' --path level.dat --name Spawn --limit 10
```

### 4. 統計並匯出地圖裡所有可翻譯文字（`scan` 與 `extract`）

想知道一張冒險地圖裡總共有多少告示牌、書本、物品、實體、指令方塊、計分板與資料包文字：

```powershell title="PowerShell"
# 快速統計各類文字各有幾筆
.\nbtcli.exe scan 'D:\WorldCopy' --summary
```

如果想把全部不重複的文字匯出成一個檔案，用記事本或 VS Code 慢慢看，請先在世界資料夾**外面**建立一個資料夾（例如 `D:\Exports`），再執行 `extract`：

```powershell title="PowerShell"
# 先在世界外建立輸出資料夾
New-Item -ItemType Directory -Path 'D:\Exports' -Force | Out-Null

# 匯出所有不重複的文字到 D:\Exports\world-text.json
.\nbtcli.exe extract 'D:\WorldCopy' --unique --output 'D:\Exports\world-text.json'
```

:::tip[為什麼 `D:\Exports` 要建在世界資料夾外面？]
為了避免在你的存檔裡留下多餘檔案，NBTExplorerCLI 規定所有匯出檔與計畫檔都必須存放在世界資料夾以外的既有資料夾中。
:::

<details>
<summary>進階查閱：讀取區塊檔（.mca）、資料包 JSON、ZIP 資源包與保留型別（--types）</summary>

除了 `level.dat`，也可以直接查閱特定區塊、資料包 JSON 或資源包壓縮檔內的文字：

<Tabs syncKey="target-kind">
  <TabItem label="地形或實體區塊 (.mca)">

```powershell title="PowerShell"
# 列出 r.0.0.mca 裡面已經生成的區塊座標
.\nbtcli.exe list 'D:\WorldCopy' --path 'region/r.0.0.mca' --limit 20

# 讀取座標 (0, 0) 區塊內的欄位
.\nbtcli.exe get 'D:\WorldCopy' --path 'region/r.0.0.mca' --chunk 0,0 --dimension minecraft:overworld --pointer /Status
```

  </TabItem>
  <TabItem label="資料包 JSON">

```powershell title="PowerShell"
.\nbtcli.exe get 'D:\WorldCopy' --path 'datapacks/custom/data/quest/advancement/root.json' --pointer /display/title
```

  </TabItem>
  <TabItem label="ZIP 資源包項目">

```powershell title="PowerShell"
.\nbtcli.exe get 'D:\WorldCopy\resources.zip' --entry 'assets/custom/lang/en_us.json' --pointer /item.custom.sword
```

  </TabItem>
  <TabItem label="保留精確型別 (--types)">

如果接下來打算用 `set` 修改這個欄位，讀取時請加上 `--types`，保留 Minecraft 精確的資料型別（如 `byte`、`short`、`int`、`long`、`float`、`string`）：

```powershell title="PowerShell"
.\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/LevelName --types
```

  </TabItem>
</Tabs>

**關於掃描快取**：`scan`、`extract` 與 `validate` 預設會在世界資料夾外的 `%LOCALAPPDATA%\nbtcli\scan\<world-id>` 保存可隨時重建的高速快取，讓你第二次掃描快非常多。想強制重掃可加 `--refresh`，不想留快取可加 `--no-cache`。

</details>
