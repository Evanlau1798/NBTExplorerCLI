本指南將帶您完成 **NBTExplorerCLI** 的下載、SHA-256 雜湊與溯源清單驗證、解壓縮獨立封裝執行環境，並在 Minecraft Java Edition 世界副本上執行第一次唯讀查閱命令（`get`、`list`、`search`、`scan` 與 `extract`）。

## 安裝與驗證四步驟

<Steps>

1. **下載並驗證 Windows x64 壓縮包**

   您可以從以下兩個官方管道取得 Windows x64 發行包（`nbtcli-win-x64.zip`）與 `SHA256SUMS.txt`：

   - **[GitHub Releases](https://github.com/Evanlau1798/NBTExplorerCLI/releases)**：通過完整發布驗證流程的正式標籤版本（`v1.0.0`）。
   - **[GitHub Actions 候選建置](https://github.com/Evanlau1798/NBTExplorerCLI/actions)**：針對特定 Commit 產出、並於無 SDK 的乾淨 Windows Server Core 容器內完成冒煙測試的建置產物（`nbtcli-windows-x64`）。

   解壓縮前，請先確認 ZIP 檔案的 SHA-256 雜湊值與隨附的 `SHA256SUMS.txt` 一致：

   ```powershell title="PowerShell"
   $zipHash = (Get-FileHash .\nbtcli-win-x64.zip -Algorithm SHA256).Hash.ToLowerInvariant()
   $expected = (Get-Content .\SHA256SUMS.txt | Select-Object -First 1).Split(' ')[0].Trim().ToLowerInvariant()
   if ($zipHash -ne $expected) { throw "SHA-256 雜湊不符！" } else { "驗證成功: $zipHash" }
   ```

2. **解壓縮獨立封裝執行環境**

   請將壓縮包完整解壓縮至獨立資料夾。本套件為**獨立封裝（Self-Contained）**，已內建固定版本的 .NET Runtime（`10.0.15`）與必要函式庫（`ICSharpCode.SharpZipLib.dll`）。請務必讓 `nbtcli.exe` 與同目錄下的 `.dll` 及 `.json` 檔案保持在一起：

   ```powershell title="PowerShell"
   Expand-Archive -Path .\nbtcli-win-x64.zip -DestinationPath .\nbtcli
   Set-Location .\nbtcli
   ```

   > [!TIP]
   > 每個發行包內皆附有 `candidate.json`，完整記錄建置版本（`1.0.0`）、Git Commit 雜湊、固定 SDK 版本（`10.0.404`）、相依套件版本，以及壓縮包內每個檔案各自的 SHA-256 雜湊值。

3. **檢查版本與命令說明**

   執行 `--version` 與 `--help` 確認執行檔可正常啟動：

   ```powershell title="PowerShell"
   .\nbtcli.exe --version
   .\nbtcli.exe --help
   ```

   ```json title="stdout (nbtcli --version)"
   {
     "schemaFamily": "nbtcli.cli",
     "schemaVersion": 1,
     "success": true,
     "command": "version",
     "outcome": "Success",
     "data": {
       "product": "nbtcli",
       "version": "1.0.0"
     },
     "error": null
   }
   ```

   若要查詢根命令支援的參數清單，請執行 `help <命令>`；查詢子命令（例如 `translate start`）則需將 `--help` 接在最後：

   ```powershell title="PowerShell"
   .\nbtcli.exe help get --ui-locale zh-TW
   .\nbtcli.exe help translate --ui-locale zh-TW
   .\nbtcli.exe translate start --help --ui-locale zh-TW
   ```

4. **準備一份世界副本**

   雖然唯讀查閱命令絕不會修改世界檔案，但在測試查詢、掃描或編輯流程前，強烈建議先複製一份獨立的 Minecraft 世界存檔（例如 `D:\WorldCopy`）。複製存檔資料夾前請先關閉 Minecraft，確保所有區塊與世界資料皆已完整寫入磁碟。

</Steps>

## 使用 `get` 讀取單一節點

`get` 可用於讀取特定的 NBT 標籤、區塊檔（`.mca`）、資料包 JSON 屬性或 ZIP 壓縮包內項目。

<Tabs syncKey="get-mode">
  <TabItem label="易讀顯示模式 (預設)">

預設情況下，`get` 會回傳簡潔易讀的 `display-json`：

```powershell title="PowerShell"
.\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/DataVersion
```

```json title="stdout (display-json)"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "get",
  "outcome": "Success",
  "data": {
    "representation": "display-json",
    "tagType": "Int",
    "value": 3953
  },
  "error": null
}
```

  </TabItem>
  <TabItem label="可逆型別模式 (--types)">

若您後續打算將輸出中的 `data.value` 修改後交給 `set` 或 `batch` 寫回世界，請加上 `--types` 以取得 `nbtcli.typed-nbt` 結構，完整保留 NBT 精確型別（如 `byte`、`short`、`int`、`long`、`float` 原始位元與型別陣列）：

```powershell title="PowerShell"
.\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/LevelName --types
```

```json title="stdout (typed-nbt)"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "get",
  "outcome": "Success",
  "data": {
    "representation": "typed-nbt",
    "tagType": "String",
    "value": {
      "schemaFamily": "nbtcli.typed-nbt",
      "schemaVersion": 1,
      "data": {
        "name": "",
        "root": {
          "tag": "string",
          "value": "Original Map Name"
        }
      }
    }
  },
  "error": null
}
```

  </TabItem>
</Tabs>

## 使用 `list` 與 `search` 探索世界結構

對世界目錄執行 `list`，可列出該世界宣告的所有維度、地形區塊檔數量與實體區塊檔數量：

```powershell title="PowerShell"
.\nbtcli.exe list 'D:\WorldCopy'
```

對 `.mca` 區塊檔執行 `list`（不加 `--chunk`）可列出所有已生成的區塊座標；執行 `search` 則可依文字內容（`--query`）、標籤名稱（`--name`）或 NBT 型別（`--type`）搜尋節點：

```powershell title="PowerShell"
.\nbtcli.exe list 'D:\WorldCopy' --path 'region/r.0.0.mca' --limit 20
.\nbtcli.exe search 'D:\WorldCopy' --path level.dat --name Spawn --limit 10
```

## 使用 `scan` 與 `extract` 掃描及抽取世界文字

`scan` 會索引世界內 21 種可翻譯或可檢視的文字來源（包含告示牌、懸掛式告示牌、書本、物品、實體、容器、指令方塊、函數、計分板、Boss 血條、進度與語言檔）：

```powershell title="PowerShell"
# 快速輸出全世界的文字來源統計摘要
.\nbtcli.exe scan 'D:\WorldCopy' --summary

# 指定單一維度掃描，並在輸出中包含解碼後的文字項目
.\nbtcli.exe scan 'D:\WorldCopy' --dimension minecraft:overworld --show-items --limit 25
```

> [!NOTE]
> 獨立的 `scan`、`extract` 與一般 `validate` 預設會在世界資料夾外建立可隨時重建的高速掃描快取（預設位於 `%LOCALAPPDATA%\nbtcli\scan\<world-id>`，亦可使用 `--cache-root` 指定世界外的其他目錄）；翻譯與寫入工作流程則使用 state root 下的獨立快取。加上 `--refresh` 可強制重新剖析，加上 `--no-cache` 則不儲存快取。

若要將解碼後的文字與精確來源位置匯出至世界資料夾外的既有目錄，請先建立父目錄後執行 `extract`：

```powershell title="PowerShell"
New-Item -ItemType Directory -Path 'D:\Exports' -Force | Out-Null
.\nbtcli.exe extract 'D:\WorldCopy' --unique --output 'D:\Exports\world-text-unique.json'
```

熟悉唯讀查閱與掃描後，請接著閱讀 **[安全編輯與中斷復原](../safe-editing/)**，了解如何先預覽變更計畫再安全寫入世界。
