翻譯一張大型冒險地圖，常常會面對數百甚至數千行散落在告示牌、書本、物品、NPC、計分板、Boss 血條、指令方塊與資料包裡的文字。**NBTExplorerCLI** 會幫你把全部文字整理成存在世界資料夾外的**翻譯進度（Session）**，切成一頁一頁慢慢翻，並自動保護所有顏色格式、點擊事件與指令語法。

在你最後一步明確執行 `apply --world-offline` 之前，你的 Minecraft 世界檔案**完全不會被改動**。

## 步驟 1：開啟翻譯進度（`translate start`）

對你的世界副本（`D:\WorldCopy`）執行 `translate start`，告訴工具地圖原本是什麼語言（`--source-language`）、你要翻成什麼語言（`--target-language`），以及每頁想要幾筆文字（`--page-size`）：

```powershell title="PowerShell"
.\nbtcli.exe translate start 'D:\WorldCopy' `
  --source-language en_us `
  --target-language zh_tw `
  --page-size 30
```

會回傳類似這樣的結果：

```json title="輸出結果"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "translate",
  "outcome": "Success",
  "data": {
    "status": {
      "sessionId": "6f9619ff-8b86-d011-b42d-00cf4fc964ff",
      "revision": 0,
      "total": 60,
      "pending": 60
    }
  },
  "error": null
}
```

把 **`sessionId`** 記下來，後面每個步驟都會用到它：
- `total`：這張地圖總共找到幾筆可翻譯文字。
- `pending`：還有幾筆尚未翻譯。
- `revision`：版本計數器，每成功提交一頁就會加 `1`。

:::note[為什麼翻譯不會把顏色和指令弄壞？]
每一行告示牌、每一頁書本或每個物品名稱都有自己獨立的 `slotId`，就算兩塊告示牌寫著同樣的英文，你也可以依不同場景翻成不同中文。而且你只需要修改純文字，底層的顏色、點擊／懸停事件與選擇器都安全保存在工具內，不怕手滑打錯符號把機關搞壞。
:::

## 步驟 2：匯出分頁、填寫譯文並提交

<Steps>

1. **匯出第 0 頁（`translate export`）**

   先在世界資料夾外建立工作資料夾（例如 `D:\Translate`），匯出第 0 頁並把可直接填寫譯文的範本存成 `reply-0.json`：

   ```powershell title="PowerShell"
   # 在世界外建立翻譯工作資料夾
   New-Item -ItemType Directory -Path 'D:\Translate' -Force | Out-Null

   # 匯出第 0 頁（記得換成你自己的 sessionId）
   $export = .\nbtcli.exe translate export 'D:\WorldCopy' `
     --session-id '6f9619ff-8b86-d011-b42d-00cf4fc964ff' `
     --page 0 `
     --output 'D:\Translate\page-0-prompt.txt' | ConvertFrom-Json

   if (-not $export.success) { throw $export.error.message }

   # 把回覆範本另存成 reply-0.json
   $export.data.replyTemplate | ConvertTo-Json -Depth 50 |
     Set-Content -Encoding utf8 'D:\Translate\reply-0.json'
   ```

   - `page-0-prompt.txt`：給你參考的原文清單與來源位置（看得出是告示牌、書本還是物品）。
   - `reply-0.json`：實際要填寫譯文並交回去的檔案。

2. **填寫 `reply-0.json`**

   用記事本或 VS Code 打開 `D:\Translate\reply-0.json`。裡面的編號欄位（如 `operationId`、`sessionId`、`slotId`、`sourceTextHash`）都保持原樣不要動，也不要刪減 `slots` 裡的任何一筆：
   - **有翻譯的項目**：把 `"state"` 改成 `"translated"`，並在 `"text"` 填入中文譯文。
   - **刻意保留原文不翻**（例如特殊符號或人名）：把 `"state"` 改成 `"unchanged"`，並把 `"text"` 設為 `null`。

3. **提交這一頁並前進到下一頁（`submit` 或 `advance`）**

   <Tabs syncKey="submit-mode">
     <TabItem label="只提交這一頁 (submit)">

   ```powershell title="PowerShell"
   .\nbtcli.exe translate submit 'D:\WorldCopy' `
     --session-id '6f9619ff-8b86-d011-b42d-00cf4fc964ff' `
     --reply 'D:\Translate\reply-0.json'
   ```

     </TabItem>
     <TabItem label="提交並直接拿下一頁 (advance)">

   `translate advance` 可以一次完成「送出譯文」並回傳「下一頁還沒翻的內容」（不帶 `--reply` 時則直接查看下一個未翻譯分頁）：

   ```powershell title="PowerShell"
   .\nbtcli.exe translate advance 'D:\WorldCopy' `
     --session-id '6f9619ff-8b86-d011-b42d-00cf4fc964ff' `
     --reply 'D:\Translate\reply-0.json'
   ```

     </TabItem>
   </Tabs>

   重複步驟 2 直到 `pending` 變成 **`0`**。中途隨時可以停下來隔天再翻，所有進度都會自動保存在世界資料夾外。

</Steps>

:::caution[翻譯期間不要改動原世界資料夾]
每次提交譯文時，工具會確認世界檔案跟開始翻譯時完全相同。如果翻譯到一半你另外改了地圖，工具會安全中止並回傳退出碼 `3`（`Conflict`），但已經翻好的譯文都會保留下來，讓你開新進度後用 `translate memory` 沿用。
:::

## 步驟 3：把翻好的成果套用到地圖

當 `pending` 降到 `0`，先執行 `translate status` 確認最新的 `revision` 編號：

```powershell title="PowerShell"
.\nbtcli.exe translate status 'D:\WorldCopy' --session-id '6f9619ff-8b86-d011-b42d-00cf4fc964ff'
```

接著照順序完成最後三步：

<Steps>

1. **產生更新計畫（`translate plan`）**

   選擇你希望玩家怎麼看到翻譯：

   <Tabs syncKey="translate-plan-mode">
     <TabItem label="直接把譯文寫進地圖 (--direct)">

   **對玩家最簡單**：直接替換地圖裡的文字，玩家下載地圖打開就能看到中文，完全不用裝資源包：

   ```powershell title="PowerShell"
   $opId = [guid]::NewGuid().ToString()

   .\nbtcli.exe translate plan 'D:\WorldCopy' `
     --session-id '6f9619ff-8b86-d011-b42d-00cf4fc964ff' `
     --revision 2 `
     --direct `
     --operation-id $opId `
     --output 'D:\Translate\world-translate-plan.json'
   ```

     </TabItem>
     <TabItem label="轉成翻譯鍵並附加語言檔 (--keys)">

   把地圖文字改成翻譯鍵，並把 `.json` 語言檔打包進資源包，支援多語言切換（詳見 **[資源包與語言檔輸出](../resources-and-packs/)**）：

   ```powershell title="PowerShell"
   $opId = [guid]::NewGuid().ToString()

   .\nbtcli.exe translate plan 'D:\WorldCopy' `
     --session-id '6f9619ff-8b86-d011-b42d-00cf4fc964ff' `
     --revision 2 `
     --keys `
     --prefix map. `
     --language-output 'resources.zip#assets/adventure/lang/zh_tw.json' `
     --operation-id $opId `
     --output 'D:\Translate\world-translate-plan.json'
   ```

     </TabItem>
   </Tabs>

   *（如果你不想改動地圖本身，只想匯出獨立 `.zip` 資源包，請看 **[資源包與語言檔輸出](../resources-and-packs/)** 的 `export-lang` 與 `create-pack`。）*

2. **關閉 Minecraft，離線套用計畫（`apply`）**

   <SafetyBanner tier="write" lang="zh-tw" />

   確認 Minecraft 已完全關閉，再執行：

   ```powershell title="PowerShell"
   .\nbtcli.exe apply 'D:\WorldCopy' `
     --plan 'D:\Translate\world-translate-plan.json' `
     --world-offline `
     --output 'D:\Translate\world-translate-receipt.json'
   ```

   套用完成後，建議立刻打開 Minecraft 進入 `D:\WorldCopy` 實際逛一圈，確認告示牌、書本與對話顯示正常！

3. **將翻譯進度標記為完成並封存（`translate seal`）**

   確認 `apply` 成功（退出碼 `0`）後，帶入相同的 `--revision`、`--operation-id` 與計畫檔的 `planHash` 封存進度：

   ```powershell title="PowerShell"
   $planHash = (Get-Content -Raw 'D:\Translate\world-translate-plan.json' | ConvertFrom-Json).data.planHash

   .\nbtcli.exe translate seal 'D:\WorldCopy' `
     --session-id '6f9619ff-8b86-d011-b42d-00cf4fc964ff' `
     --revision 2 `
     --operation-id $opId `
     --plan-hash $planHash
   ```

   `seal` 會核對硬碟上已完成的寫入紀錄，確認地圖真的寫完後才會關閉進度。

</Steps>

## 遇到未支援來源時匯出翻譯草稿

掃描能讀取來源、但尚未判定文字用途時，可用 `translate fallback` 匯出選定標籤或指令行、候選文字路徑與回覆範本。支援 NBT、JSON、SNBT 和 UTF-8 純文字。

```powershell
.\nbtcli.exe translate fallback 'D:\WorldCopy' `
  --path 'datapacks/story/data/story/functions/dialogue.mcfunction' --line 12 `
  --output 'D:\Drafts\dialogue-context.json'
```

NBT 檔可以用 `--pointer` 選標籤，省略時會讀取根標籤。讀取區塊時需指定 `--chunk x,z`，獨立區域檔還需指定維度。ZIP 可用 `--entry` 選定成員。獨立 SNBT 片段使用 `--format snbt`。行號從 1 開始，預設讀取指令行末尾的結構化參數。若標籤嵌在其他格式中，可用 `--byte-range 起始,長度` 指定從 0 開始的 UTF-8 位元組位置，並選擇 `--format json`、`snbt` 或 `text`。指定 `--format text` 時會產生純文字草稿，結果會標明 `structureVerified: false`。

把 `data.replyTemplate` 存成另一個 JSON 檔，只填入要翻譯欄位的 `text`，其餘可留 `null`。再次執行相同選取條件，加上 `--reply` 和新的輸出檔名。

```powershell
.\nbtcli.exe translate fallback 'D:\WorldCopy' `
  --path 'datapacks/story/data/story/functions/dialogue.mcfunction' --line 12 `
  --reply 'D:\Drafts\dialogue-reply.json' --output 'D:\Drafts\dialogue-validated.json'
```

譯後片段在 `data.content`。CLI 會比對原始來源和候選欄位、驗證格式碼、數值和私用區字元，並保留結構化草稿的其他欄位。選取單行時，輸出必須維持一個物理行，能以跳脫表示的字串換行仍可保留。即使只選取單一檔案，也請將草稿匯出到 Minecraft 世界資料夾以外。結果會標明 `gameplayVerified: false`。請先在世界副本核對指令或畫面，再將草稿納入編輯。原始來源與掃描狀態會保留。

## 選用進階小幫手

一般地圖翻譯不需要用到以下功能，但在翻譯超大型地圖時非常實用：

- **只翻地圖的一部分**：在 `translate start` 加上 `--dimension`、`--region`、`--types`、`--path` 或 `--match-pattern`（例如 `--types Sign,Book` 只翻告示牌跟書本）。
- **翻譯經典舊版地圖（1.2.5 / 1.5.2 / 1.6.4 / 1.8.1）**：在 `translate start` 加上 `--minecraft-version 1.8.1`（或 `1.2.5`、`1.5.2`、`1.6.4`）。純文字字數上限請看 **[支援版本與疑難排解](../support-and-troubleshooting/)**。
- **隨時查進度或看關聯文本**：
  - 查進度：`.\nbtcli.exe translate status 'D:\WorldCopy' --session-id <id>`
  - 查單筆文字：`.\nbtcli.exe translate get 'D:\WorldCopy' --session-id <id> --slot-id <slot-id>`
  - 看同一本書／同一塊告示牌的群組：`.\nbtcli.exe translate groups 'D:\WorldCopy' --session-id <id> --limit 50`

<details>
<summary>進階操作：術語表（glossary）、譯者備註（note）、翻譯記憶（memory）、重置與預設偏好（agent）</summary>

### 查看或更新術語表與備註

```powershell title="PowerShell"
# 查看目前儲存的專有名詞術語表或備註
.\nbtcli.exe translate glossary 'D:\WorldCopy' --session-id '<session-id>'
.\nbtcli.exe translate note 'D:\WorldCopy' --session-id '<session-id>'
```

若要新增術語、新增備註、跳到指定頁碼，或把某些槽位重置回待翻譯，請準備 `nbtcli.session-command` 格式的 JSON 檔並透過 `--request` 傳給 `translate glossary`、`translate note`、`translate jump` 或 `translate reset`（執行確認重置時加 `--confirm`）。範本見 **[完整命令參考](../command-reference/)**。

### 從舊翻譯進度沿用譯文（`translate memory`）

地圖更新後重新開了新進度時，可以從舊進度查詢相容的歷史譯文：

```powershell title="PowerShell"
.\nbtcli.exe translate memory 'D:\WorldCopy' `
  --session-id '<目前-session-id>' `
  --slot-id '<完整-slot-id>' `
  --source-sessions '<舊-session-id>' `
  --glossary-version '<術語表版本號>'
```

### 為外部工具儲存預設語言偏好（`agent`）

如果想幫這個世界固定存下預設的來源／目標語言與每頁筆數，可選用 `agent` 指令：

```powershell title="PowerShell"
New-Item -ItemType Directory -Path 'D:\Translate' -Force | Out-Null

# 1. 匯出偏好設定問卷
.\nbtcli.exe agent setup 'D:\WorldCopy' `
  --source-language en_us `
  --target-language zh_tw `
  --output 'D:\Translate\agent-questionnaire.json'

# 2. 在檔案裡填寫 configuration.agentName 後提交儲存
.\nbtcli.exe agent submit 'D:\WorldCopy' --request 'D:\Translate\agent-questionnaire.json'

# 3. 隨時查看已儲存的設定
.\nbtcli.exe agent status 'D:\WorldCopy'
```

`agent` 只會把偏好存在本機狀態目錄內，絕不會主動連網，也不會修改你的世界存檔。

</details>
