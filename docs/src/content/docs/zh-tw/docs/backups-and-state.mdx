**NBTExplorerCLI** 會把所有工具自己的資料——掃描快取、翻譯進度、備份檔案與復原紀錄——全部放在**你的 Minecraft 世界資料夾之外**。不管你掃描幾次地圖或開了幾個翻譯進度，都不會把原本的存檔資料夾弄亂。

---

## 1. 修改前先幫世界建一份備份（`backup`）

執行 `backup` 會把整個世界（或加上 `--path level.dat` 只備份單一檔案）安全存到外部備份區：

```powershell title="PowerShell"
New-Item -ItemType Directory -Path 'D:\Backups' -Force | Out-Null

.\nbtcli.exe backup 'D:\WorldCopy' `
  --suffix before-translation `
  --output 'D:\Backups\before-translation-manifest.json'
```

輸出範例：

```json title="輸出結果"
{
  "schemaFamily": "nbtcli.cli",
  "schemaVersion": 1,
  "success": true,
  "command": "backup",
  "outcome": "Success",
  "data": {
    "manifestHash": "4b227777d4dd1fc61c6f884f48641d02b4d121d3fd328cb08b5531fcacdabf8a",
    "stateRoot": "C:\\Users\\Player\\AppData\\Local\\nbtcli\\worlds\\4a8b9c...",
    "backupPath": "C:\\Users\\Player\\AppData\\Local\\nbtcli\\worlds\\4a8b9c...\\backup_before-translation_20261118T070000Z_a1b2c3.json",
    "namedManifestPublished": true
  },
  "error": null
}
```

記下裡面的 **`manifestHash`**（以及 `stateRoot`）！

:::caution[記得同時保留 `objects/` 資料夾與 `manifestHash`]
`backup` 產生的 `.json` 檔案只是紀錄「有哪些檔案」的**清單索引**，真正備份下來的檔案資料都存在 `stateRoot` 底下的 `objects/` 資料夾裡。將來還需要還原的話，千萬別把 `objects/` 刪掉！
:::

## 2. 還原整個世界或單一損壞檔案（`restore`）

<SafetyBanner tier="write" lang="zh-tw" />

不管是整個存檔想退回備份點，還是只有其中一個檔案（例如 `level.dat`）壞掉或被誤刪，都可以用 `restore` 救回：

<Steps>

1. **先預覽還原計畫**

   ```powershell title="PowerShell"
   # 預覽還原整個世界（若只想救回單一檔案，加上 "--path level.dat"）
   .\nbtcli.exe restore 'D:\WorldCopy' `
     --manifest-hash '4b227777d4dd1fc61c6f884f48641d02b4d121d3fd328cb08b5531fcacdabf8a' `
     --output 'D:\Backups\restore-plan.json'
   ```

2. **關閉 Minecraft，離線套用還原計畫**

   ```powershell title="PowerShell"
   .\nbtcli.exe apply 'D:\WorldCopy' `
     --plan 'D:\Backups\restore-plan.json' `
     --world-offline
   ```

   *（若備份或預覽時有指定自訂 `--state-root`，這裡請帶上同一個 `--state-root`。）*

</Steps>

## 3. 工具檔案都存在哪裡？哪些可以放心清理？

預設情況下，所有外部資料都放在 Windows 的本機應用程式資料夾（`%LOCALAPPDATA%\nbtcli\`）：

<FileTree>
- %LOCALAPPDATA%\nbtcli\
  - worlds\
    - 4a8b9c1d2e3f... (每個世界一個資料夾)
      - cache\ (翻譯與編輯用的加速快取)
      - sessions\ (翻譯進度、已翻譯文與術語表)
      - agent\ (選用的預設語言設定)
      - objects\ (真正的備份與回滾原始檔 — 請保留！)
      - journals\ (寫入紀錄與中斷復原日誌 — 請保留！)
      - backup_before-translation_20261118T070000Z_a1b2c3.json
  - scan\
    - 4a8b9c1d2e3f...\ (獨立 scan / extract / validate 用的快取)
</FileTree>

### 資料夾清理對照表

| 資料夾／檔案 | 裡面裝什麼 | 可以安心刪掉嗎？ |
| --- | --- | --- |
| `scan/` 與 `worlds/<id>/cache/` | 讓重複掃描更快的高速快取。 | **可以。** 下次掃描會自動重建（或執行 `scan --refresh` 更新）。 |
| `sessions/` | 你的翻譯進度、已提交頁數、備註與術語表。 | **翻譯期間請保留。** 等整張地圖確定翻完封存後再清理。 |
| `agent/` | 透過 `agent setup` 記住的預設語言與分頁設定。 | **看需求。** 不需要記住預設值就可以刪。 |
| `objects/` 與 `backup_*.json` | `restore` 與 `recover --rollback` 還原時真正依賴的原始檔案內容。 | **還需要還原就別刪！** |
| `journals/` | `status` 與 `recover` 判斷寫入進度的紀錄。 | **寫入中斷（退出碼 7）期間絕對不可刪除。** |

<details>
<summary>進階：用 --state-root 把資料存到指定磁碟或區分不同世界副本</summary>

如果你同時保留多份世界副本，或想把備份和翻譯紀錄存到 D 槽（例如 `D:\NbtState\MyMap`），只要在相關指令加上 `--state-root 'D:\NbtState\MyMap'` 即可。

- 同一個專案關聯的 `plan`、`apply`、`status`、`recover`、`backup`、`restore`、`translate`、`agent` 必須帶入**相同**的 `--state-root`。
- 建議替每份獨立的世界副本指定各自的 `--state-root`；每次重新複製世界資料夾時，請重新掃描並產生新的計畫檔。

</details>
