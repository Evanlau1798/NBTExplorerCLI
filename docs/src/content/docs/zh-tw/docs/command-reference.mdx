## 指令基本語法規則

- **查詢指令說明**：主指令請打 `.\nbtcli.exe help <指令>`；子命令請把 `--help` 放在最後，例如 `.\nbtcli.exe translate start --help`（打 `nbtcli help translate start` 會回傳退出碼 `2`）。
- **常用縮寫**：任何指令都能用 `-h` 代替 `--help`；`--version` 或 `-v` 會印出版本號。
- **切換訊息語言**：在任何指令加上 `--ui-locale zh-TW`（預設）或 `--ui-locale en-US`，即可切換錯誤與說明語言，不影響 JSON 鍵名或翻譯目標語言。
- **參數寫法**：帶值選項支援 `--option value` 或 `--option=value`；如果路徑以 `-` 開頭，先加 `--` 分隔。
- **統一輸出格式**：每個指令都會向 `stdout` 輸出單行 UTF-8 JSON（`schemaFamily: "nbtcli.cli"`、`schemaVersion: 1`）。

會從檔案或標準輸入（`-`）讀取 JSON 的命令，執行前都會嚴格檢查 `schemaFamily` 與 `schemaVersion: 1`：

| 輸入 Schema Family | 對應指令與參數 |
| --- | --- |
| `nbtcli.typed-nbt` | `set --value <json>` 或 `set --value-file <檔案\|->` |
| `nbtcli.operations` | `batch <檔案\|-> --world <目錄>` 或 `plan <目錄> --request <檔案\|->` |
| `nbtcli.patch-plan` | `apply <目錄> --plan <檔案\|->` |
| `nbtcli.session-reply` | `translate submit --reply <檔案\|->` 或 `translate advance --reply <檔案\|->` |
| `nbtcli.session-command` | `translate jump`、`note`、`glossary` 或 `reset`（`--request <檔案\|->`） |
| `nbtcli.agent-questionnaire` | `agent submit <目錄> --request <檔案\|->` |

### 可直接複製的 JSON 範本

<Tabs syncKey="input-schema">
  <TabItem label="nbtcli.typed-nbt">

供 `set --value` 或 `set --value-file` 使用。建議一律先執行 `nbtcli get <世界> --path <相對路徑> --pointer <指標> --types`，取出 `data.value` 後只改 `data.root.value`：

```json title="value-typed-nbt.json"
{
  "schemaFamily": "nbtcli.typed-nbt",
  "schemaVersion": 1,
  "data": {
    "name": "",
    "root": {
      "tag": "string",
      "value": "Updated Map Title"
    }
  }
}
```

  </TabItem>
  <TabItem label="nbtcli.operations">

供 `nbtcli plan <世界> --request <檔案|->` 與 `nbtcli batch <檔案|-> --world <世界>` 使用（1 至 100,000 筆具唯一 `id` 的操作）。可從單筆 `set` 預覽計畫的 `data.operations` 快速組合：

```powershell title="從預覽計畫產生操作集"
$preview = Get-Content -Raw 'D:\Plans\level-name-plan.json' | ConvertFrom-Json
@{
  schemaFamily = 'nbtcli.operations'
  schemaVersion = 1
  data = @{ operations = @($preview.data.operations) }
} | ConvertTo-Json -Depth 100 | Set-Content -Encoding utf8 'D:\Plans\ops.json'
```

### PowerShell 自動化腳本範本

```powershell title="PowerShell"
$raw = .\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/DataVersion --ui-locale zh-TW
$exitCode = $LASTEXITCODE
$response = $raw | ConvertFrom-Json

if ($exitCode -eq 7 -or $response.outcome -eq 'RecoveryRequired') {
  Write-Error "偵測到未完成的寫入（planHash: $($response.data.planHash)），請先執行 'nbtcli status' 與 'nbtcli recover'。"
  exit 7
}

if ($exitCode -ne 0 -or -not $response.success) {
  throw "nbtcli 執行失敗（退出碼 $exitCode，錯誤碼 $($response.error.code)）：$($response.error.message)"
}

Write-Output "讀取到的 DataVersion：$($response.data.value)"
```
