## 全域 CLI 規則

若要查詢個別子命令（例如 `translate start` 或 `agent setup`）的說明，請將 `--help` 接在子命令之後，例如 `nbtcli translate start --help`（執行 `nbtcli help translate start` 會回傳結束代碼 `2`）。

- **單一 JSON 輸出格式**：每個命令皆只會向標準輸出（`stdout`）寫入單行 UTF-8 JSON 封套（`schemaFamily: "nbtcli.cli"`，`schemaVersion: 1`）。
- **全域介面訊息語言（`--ui-locale`）**：可在任何命令前後加上 `--ui-locale zh-TW`（預設）或 `--ui-locale en-US`，切換錯誤訊息與說明文字的語言；此選項不會影響翻譯來源與目標語言參數（`--source-language`、`--target-language`、`--lang`、`--original-lang`、`--target-lang`）。
- **選項語法規則**：帶值選項支援 `--option value` 或 `--option=value` 兩種寫法；布林旗標不帶值。若目標路徑本身以連字號（`-`）開頭，請先加上 `--` 結束選項剖析。
- **根命令與說明別名**：
  - 根層級的 `--help` 與 `-h` 等同於執行 `help`。
  - 根層級的 `--version` 與 `-v` 等同於執行 `version`。
  - 任何命令皆可使用 `-h` 作為 `--help` 的簡寫。

## 檔案與標準輸入（`-`）JSON Schema 對照表

凡是會從檔案或標準輸入（`-`）讀取結構化 JSON 的命令，執行前皆會嚴格驗證 `schemaFamily` 與 `schemaVersion`：

| 輸入 Schema Family | 接收此格式的命令與參數 |
| --- | --- |
| `nbtcli.typed-nbt` | `set --value <json>` 或 `set --value-file <檔案\|->` |
| `nbtcli.operations` | `batch <檔案\|-> --world <目錄>` 或 `plan <目錄> --request <檔案\|->` |
| `nbtcli.patch-plan` | `apply <目錄> --plan <檔案\|->` |
| `nbtcli.session-reply` | `translate submit --reply <檔案\|->` 或 `translate advance --reply <檔案\|->` |
| `nbtcli.session-command` | `translate jump`、`note`、`glossary` 或 `reset`（透過 `--request <檔案\|->`） |
| `nbtcli.agent-questionnaire` | `agent submit <目錄> --request <檔案\|->` |

```powershell title="Build an operation set from a preview"
$preview = Get-Content -Raw 'D:\Plans\level-name-plan.json' | ConvertFrom-Json
@{
  schemaFamily = 'nbtcli.operations'
  schemaVersion = 1
  data = @{ operations = @($preview.data.operations) }
} | ConvertTo-Json -Depth 100 | Set-Content -Encoding utf8 'D:\Plans\ops.json'
```

## PowerShell 自動化腳本與結束代碼解析範本

在 PowerShell 腳本或 CI 流程中呼叫 `nbtcli.exe` 時，可直接將單行輸出交由 `ConvertFrom-Json` 解析，並同時檢查 `$LASTEXITCODE` 與 `$response.success`：

```powershell title="PowerShell"
$raw = .\nbtcli.exe get 'D:\WorldCopy' --path level.dat --pointer /Data/DataVersion --ui-locale zh-TW
$exitCode = $LASTEXITCODE
$response = $raw | ConvertFrom-Json

if ($exitCode -eq 7 -or $response.outcome -eq 'RecoveryRequired') {
  Write-Error "偵測到未完成的寫入（planHash: $($response.data.planHash)），請先執行 'nbtcli status' 與 'nbtcli recover'。"
  exit 7
}

if ($exitCode -ne 0 -or -not $response.success) {
  throw "nbtcli 執行失敗（結束代碼 $exitCode，錯誤碼 $($response.error.code)）：$($response.error.message)"
}

Write-Output "讀取到的 DataVersion：$($response.data.value)"
```
