本頁完整列出 **NBTExplorerCLI**（`nbtcli.exe`）註冊的所有命令與子命令，內容與自動化測試驗證的機器命令表（`nbtcli.command-surface` 版本 `1`）完全同步。

## 全域協定與旗標規則

- **單行 JSON 標準輸出**：所有指令皆會在標準輸出（`stdout`）回傳單一 UTF-8 JSON 信封物件（`schemaFamily: "nbtcli.cli"`，`schemaVersion: 1`）。
- **介面顯示語言（`--ui-locale`）**：可於指令前後加上 `--ui-locale zh-TW`（預設）或 `--ui-locale en-US`，僅改變說明與錯誤訊息文字，不影響地圖翻譯與資源包的語言設定（`--source-language`、`--target-language`、`--lang`、`--original-lang`、`--target-lang`）。
- **參數語法**：帶值參數支援 `--option value` 或 `--option=value` 兩種寫法；布林旗標不帶值。若檔案路徑以連字號開頭，可使用 `--` 結束旗標解析。
- **支援的簡寫別名（Aliases）**：
  - 根命令 `--help` 與 `-h` 等同於 `help`。
  - 根命令 `--version` 與 `-v` 等同於 `version`。
  - 所有命令皆支援以 `-h` 查詢該命令的 `--help` 說明。

## 結構化檔案與標準輸入（`-`）格式對照

當指令透過檔案路徑或標準輸入（`-`）讀取 JSON 時，皆會先驗證對應的 `schemaFamily` 與 `schemaVersion`：

| 輸入 JSON Schema Family | 使用該格式的指令與參數 |
| --- | --- |
| `nbtcli.typed-nbt` | `set --value <json>` 或 `set --value-file <檔案\|->` |
| `nbtcli.operations` | `batch <檔案\|-> --world <世界目錄>` 或 `plan <世界目錄> --request <檔案\|->` |
| `nbtcli.patch-plan` | `apply <世界目錄> --plan <檔案\|->` |
| `nbtcli.session-reply` | `translate submit --reply <檔案\|->` 或 `translate advance --reply <檔案\|->` |
| `nbtcli.session-command` | `translate jump`、`note`、`glossary` 或 `reset` 搭配 `--request <檔案\|->` |
| `nbtcli.agent-questionnaire` | `agent submit <世界目錄> --request <檔案\|->` |
